나만의 자료실

서버가 승인한 로그인 세션에서 기존 자료실을 엽니다. 실제 개인정보나 운영 자료는 입력하지 마세요.

앱 설치 상태

브라우저에서 실행 중설치 표시만으로 기기 승인이 된 것은 아닙니다.

오프라인에서는 보호 자료를 표시하지 않습니다. 연결을 복구한 뒤 로그인 세션 승인을 다시 확인하세요.

로그인 세션마다 별도로 승인이 필요합니다. 새로 로그인한 세션은 기존 승인 상태를 이어받지 않습니다.

로그인 세션 승인

서버 승인 상태를 확인합니다.

승인 요청은 pending으로 저장됩니다. 운영자가 서버에서 승인하기 전에는 자료를 열 수 없습니다. 이 흐름은 물리 기기를 증명하지 않습니다.
